# 기업 제휴 안내문 페이지 사용설명서

민병철유폰 B2B 제휴 안내문 다운로드 페이지(`index.html`)를 매달 관리하기 위한 설명서입니다. 개발 지식이 없어도 따라 할 수 있도록 작성했어요.

---

## 1. 이 페이지는 뭔가요?

기업 제휴 담당자에게 **이번 달 제휴 안내문(PC/모바일 이미지)**을 공유하는 다운로드 페이지입니다.

- 방문자는 PC버전 · 모바일버전 중 필요한 이미지를 골라 내려받습니다.
- 매달 바뀌는 건 **월(月)과 안내문 이미지 2장**뿐입니다.
- 디자인·문구는 손대지 않아도 됩니다.

---

## 2. 폴더 구조

```
프로젝트 폴더/
├── index.html          ← 이 페이지 (거의 안 건드림)
├── files/              ← 매달 교체하는 안내문 이미지
│   ├── 26.8월 B2B2C 안내문_pc.png
│   └── 26.8월 B2B2C 안내문_MO.png
└── assets/             ← 로고·배경 (건드릴 일 없음)
    ├── logo.svg
    ├── bg-pc.jpg
    └── bg-mo.jpg
```

---

## 3. ⚠️ 매달 이것만 하세요 (2단계)

### STEP 1. 새 안내문 이미지를 `files` 폴더에 넣기

새로 만든 PC·모바일 안내문 PNG 2장을 `files` 폴더에 업로드합니다.

> ## 🚨🚨 절대 주의 🚨🚨
> ### **`files` 폴더 안의 파일을 "전부 삭제"하지 마세요!**
>
> - 이전 달 파일을 지우고 싶더라도, **한 번에 전체 선택 → 삭제는 금지**입니다.
> - 실수로 폴더를 통째로 비우면 페이지의 다운로드 버튼이 깨져(파일을 못 찾음) 방문자에게 오류가 납니다.
> - **새 파일을 먼저 추가**한 뒤, 필요하면 이전 달 파일만 골라서 하나씩 지우세요.
> - 가장 안전한 방법: **이전 파일은 그냥 두고 새 파일만 추가**하는 것입니다.

### STEP 2. `index.html`의 CONFIG 5줄만 수정하기

`index.html` 파일 위쪽의 **`★ 매달 여기만 수정하세요 ★`** 표시가 있는 CONFIG 부분을 엽니다.

```javascript
const CONFIG = {
  MONTH: 8,                                        // ① 안내문 월 (숫자만)
  FILE_PC: "./files/26.8월 B2B2C 안내문_pc.png",   // ② PC 이미지 파일 경로
  FILE_MO: "./files/26.8월 B2B2C 안내문_MO.png",   // ③ 모바일 이미지 파일 경로
  PHONE: "02-6956-0509",                           // ④ 제휴 문의 전화번호
  CHAT_URL: ""                                     // ⑤ 채널톡 링크 (없으면 빈칸)
};
```

| 항목 | 설명 | 예시 |
|------|------|------|
| `MONTH` | 안내문의 월. **숫자만** 적어요. 제목·버튼·저장 파일명에 자동 반영됩니다. | `9` (9월이면) |
| `FILE_PC` | STEP 1에서 넣은 **PC 이미지의 실제 파일명**과 정확히 일치시켜야 합니다. | `"./files/(넣은 PC 파일명).png"` |
| `FILE_MO` | 넣은 **모바일 이미지의 실제 파일명**과 정확히 일치시켜야 합니다. | `"./files/(넣은 모바일 파일명).png"` |
| `PHONE` | 제휴 문의 전화번호. 바뀔 때만 수정. | `"02-6956-0509"` |
| `CHAT_URL` | 채널톡 상담 링크. **빈 `""`이면 링크가 숨겨집니다.** | `"https://.../chat"` |

> 💡 **파일명은 글자·띄어쓰기·대소문자까지 똑같아야** 합니다. `_pc`와 `_PC`도 다르게 인식돼요.

## 4. 자주 하는 실수 & 해결

| 증상 | 원인 | 해결 |
|------|------|------|
| 다운로드 버튼을 눌러도 이미지가 안 열림 | CONFIG의 파일 경로와 실제 파일명이 다름 | `FILE_PC`/`FILE_MO`를 `files` 폴더의 진짜 파일명과 똑같이 맞추기 |
| 다운로드가 아예 안 됨 / 오류 | `files` 폴더의 파일을 지워버림 | 안내문 이미지를 다시 `files` 폴더에 넣기 (STEP 1 참고) |
| 제목의 월이 안 바뀜 | `MONTH` 숫자를 안 고침 | `MONTH` 값을 이번 달 숫자로 변경 |
| 저장되는 파일명이 이상함 | 정상입니다. `유폰_9월_기업제휴_안내문_PC.png` 형태로 자동 지정돼요 | — |

## 5. GA4 다운로드 추적 (선택)

다운로드 클릭 수를 GA4로 보고 싶다면, `index.html` 맨 아래 주석 안내에 따라 `G-XXXXXXX`를 실제 측정 ID로 바꿔 `<head>`에 넣으면 됩니다. 설치하지 않아도 페이지는 정상 작동해요.
